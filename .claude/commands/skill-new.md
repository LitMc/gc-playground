# SKILL 新規作成フロー

新しいスラッシュコマンド（SKILL）を `.claude/commands/` に追加するためのガイド。
このコマンドはエージェント自身が「このフローを SKILL 化したい」と判断したときに参照・実行する。

## SKILL 化の判断基準

以下のいずれかに該当する場合、SKILL 化を検討する：

- 同じ手順を **3回以上** 手動で実行した
- 手順が複数ステップにわたり、毎回確認が必要
- チームメンバー（将来の自分・他エージェント）が迷いなく実行できるようにしたい

## 手順

### 1. SKILL の概要を決める

- **名前**: `動詞-名詞` 形式（例: `build-verify`, `pr-check`, `timing-measure`）
- **目的**: 1〜2 文で何をするコマンドか
- **呼び出し方**: `/名前` でどんな状況に使うか

### 2. `.claude/commands/<name>.md` を作成する

```markdown
# SKILL 名

1行の目的説明。

## 手順

1. ステップ1
2. ステップ2
...

## 使用例

具体的な呼び出し例。
```

### 3. CLAUDE.md の「カスタム SKILL 一覧」に追記する

```markdown
| `/skill-name` | 目的の説明 |
```

### 4. 動作確認

`/<name>` を呼び出して意図通りに動作することを確認する。

## 命名規則

| パターン | 用途 | 例 |
|---------|------|---|
| `build-*` | ビルド関連 | `build-verify`, `build-target` |
| `pr-*` | PR 関連 | `pr-check`, `pr-merge` |
| `measure-*` | 計測関連 | `measure-timing`, `measure-roi` |
| `agents-*` | エージェント管理 | `agents-review` |
